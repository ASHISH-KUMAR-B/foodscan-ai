# FoodScan AI

FoodScan AI is a web application that helps users understand the ingredients in packaged food products.

## Features

- Scan ingredient labels using a phone camera
- Upload images from desktop
- OCR-based ingredient extraction
- Ingredient safety analysis
- Country-wise banned ingredient information
- Health score
- Multi-language support
- User login and scan history

## Tech Stack

### Frontend

- React
- Tailwind CSS
- Axios
- React Router

### Backend

- Node.js
- Express.js
- MongoDB

### DevOps

- GitHub
- GitHub Actions
- Vercel
- Render
